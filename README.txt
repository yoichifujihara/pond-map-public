------------------------------------------------------------
1. このサイトの目的
------------------------------------------------------------

石川県内の農業用ため池について、

  ・位置
  ・ため池名
  ・市町
  ・所在地
  ・基礎的な情報

を、地図上で一般の方が確認できるようにするための
シンプルなWebページです。

浸水想定、ハザードマップ、防災解析などの機能は
含んでいません。


------------------------------------------------------------
2. 公開方法
------------------------------------------------------------

このフォルダの中身を、フォルダ構成を変えずに
そのままWebサーバへ置いてください。それだけで公開できます。

  (1) 受け取ったZIPファイルを解凍します。
  (2) 解凍してできたフォルダの中身を、
      Webサーバの公開用フォルダへコピーします。
  (3) ブラウザで index.html のURLを開いて表示を確認します。

【重要】

  ・フォルダの名前や配置を変更しないでください。
    index.html から
      assets フォルダ
      data フォルダ
    を参照しているため、構成を変えると地図が表示されなくなります。

  ・サイト全体の直下（例 https://（県のドメイン）/tameike/ ）でも、
    サブフォルダの中でも動作します。
    ファイルの参照はすべて相対パスで書いてあります。

  ・以下のファイルは公開サーバへ置かなくても動作します。
    （置いても害はありませんが、通常は不要です）

      CLAUDE.md   … 開発方針をまとめた内部用の文書
      README.txt  … この説明書
      SECURITY.md … セキュリティ担当者向けの説明

3. 必要な環境（サーバ要件）
------------------------------------------------------------

静的ファイル（HTML・CSS・JavaScript・JSON・画像）を
HTTPSで配信できるWebサーバがあれば動作します。

次のものは一切必要ありません。

  ・PHP
  ・Python
  ・Node.js
  ・データベース
  ・CMS
  ・APIキーやアカウントの取得
  ・クラウドサービスの契約

閲覧者側は、一般的なWebブラウザ
（Microsoft Edge、Google Chrome、Safari、Firefox の最新版）
をご利用ください。

なお、ファイルをダブルクリックして開く方法
（アドレスが file:/// で始まる開き方）では、
ブラウザの安全上の制限によりデータを読み込めません。
必ずWebサーバに置いた状態でご確認ください。

4. 外部との通信について
------------------------------------------------------------

「ページを開いただけで自動的に発生する通信」と、
「利用者がリンクを押したときだけ発生する通信」は別のものです。
分けて説明します。

【1】ページを開いたときに自動的に発生する通信

  次の1か所だけです。

  ・国土地理院 地図タイル（背景地図）
      https://cyberjapandata.gsi.go.jp/xyz/pale/

  背景地図を表示するために必要な通信です。

【2】利用者がリンクを押したときだけ発生する通信

  各ため池をクリックすると表示される情報の下に、
  「外部地図で確認」として次の3つのリンクがあります。

  ・地理院地図           https://maps.gsi.go.jp/
  ・Googleマップ         https://www.google.com/maps
  ・重ねるハザードマップ https://disaportal.gsi.go.jp/

  これらは、そのため池の緯度・経度の地点を、
  それぞれの公式サイトで開くための「ふつうのリンク」です。

  利用者がリンクを押したときに、新しいタブでそのサイトが開くだけで、
  ページを表示しただけでは Googleやハザードマップへは一切通信しません。

  Googleマップ等のAPI・JavaScript・SDKを本サイトで使用しているものでは
  ありません。地図を本サイトの中に埋め込んでいるわけでもありません。

これ以外の外部サービスは使用していません。

  ・外部のJavaScript読み込み  … ありません
  ・外部のCSS読み込み          … ありません
  ・外部のWebフォント          … ありません
  ・APIキー                    … ありません
  ・アクセス解析               … ありません
  ・SNSの読み込み              … ありません

詳しくは SECURITY.md をご覧ください。

5. データの更新方法
------------------------------------------------------------

ため池のデータは、次の1ファイルだけです。

  data/noto_ponds.json

このファイルを新しいものに置き換えるだけで更新できます。
ほかのファイルを変更する必要はありません。

  (1) 新しい noto_ponds.json を用意します。
  (2) data フォルダの中の noto_ponds.json を上書きします。
      （元のファイルは念のため保管しておいてください）
  (3) ブラウザで表示を確認します。
      表示が変わらない場合は、ブラウザの再読み込み
      （Ctrl キーを押しながら F5 キー）をお試しください。

データの形式（1件分の例）

  {
    "name": "道閑池",
    "city": "七尾市",
    "addr": "千野町",
    "lat": 36.99556,
    "lon": 136.973,
    "dam_h": 7.0,
    "crest": 26.0,
    "vol": 39.0,
    "area": 0.01
  }

  name  … ため池名
  city  … 市町名（旧市町名が括弧で入っていても構いません）
  addr  … 所在地
  lat   … 緯度（数値）
  lon   … 経度（数値）
  dam_h / crest / vol / area … 数値項目（値がない場合は null）

補足

  ・市町のプルダウンには、city の括弧より前の部分を使います。
    例：「七尾市（鹿島郡中島町）」は「七尾市」として扱います。
    （ため池をクリックしたときの表示には、元の値をそのまま使います）

  ・緯度・経度が数値でない場合や、日本国内から大きく外れた値の場合は、
    その1件だけを表示せず、他のため池は正常に表示します。

6. 表示する項目名・単位を変える場合
------------------------------------------------------------

ため池をクリックしたときに表示される

  堤高 / 堤頂長 / 貯水量 / 面積

の項目名と単位は、次のファイルの上のほうにまとめてあります。

  assets/js/app.js

その中の

  numericFields:

と書かれている部分の label（項目名）と unit（単位）を
書き換えてください。

  例）貯水量の単位を「千m3」と表示したい場合
      { key: 'vol', label: '貯水量', unit: '千m3' },

※ 元データからは正式な単位が確定できないため、
   初期状態では単位を表示していません。
   公開前に、正式な項目名・単位をご確認ください。

【外部地図リンクを変更・削除する場合】

同じ assets/js/app.js の中の

  externalLinks:

と書かれた部分に、3つのリンク（地理院地図・Googleマップ・
ハザードマップ）の設定がまとまっています。

  ・リンク名を変えたい場合 … label を書き換えてください。
  ・リンクを減らしたい場合 … 不要なものを { から } まで削除してください。

たとえばGoogleマップへのリンクを掲載しない方針となった場合は、
label が 'Googleマップ' の { … } のかたまりを削除するだけで済みます。

7. 注意書きの文章を変える場合
------------------------------------------------------------

ページ下部の注意書きは、index.html の中の

  <section class="notes">

と書かれた部分にあります。
その中の文章を書き換えてください。

ページのタイトル「石川県 ため池マップ」を変える場合は、
index.html の中の

  <title>            … ブラウザのタブに出る名前
  <h1>               … ページの見出し

の2か所を書き換えてください。

9. 簡単な動作確認方法
------------------------------------------------------------

Webサーバへ置いたあと、ブラウザで開いて次をご確認ください。

  □ ページが表示され、地図（淡色地図）が出る
  □ 地図上に青い丸がたくさん表示される
  □ 青い丸をクリックすると、ため池名などが表示される
  □ 「市町」のプルダウンを選ぶと、その市町だけが表示される
  □ 「ため池名」に文字を入れて「検索」を押すと候補が出る
  □ 候補をクリックすると、その場所へ地図が移動する
  □ 「クリア」を押すと、最初の状態に戻る
  □ ため池の情報の下に「外部地図で確認」として
     「地理院地図」「Googleマップ」「ハザードマップ」の
     3つのリンクが表示される
  □ それぞれのリンクを押すと、新しいタブでそのため池付近が開く
  □ 地図の右下に「国土地理院」の表示が出ている
  □ スマートフォンでも操作できる

うまく表示されない場合の確認点

  ・地図は出るがため池が出ない
      → data/noto_ponds.json が正しい場所にあるか確認してください。

  ・地図（背景）が真っ白になる
      → 庁内ネットワークから
        cyberjapandata.gsi.go.jp への通信が
        許可されているか、ネットワーク担当者へご確認ください。

  ・何も表示されない
      → assets フォルダごとコピーされているか確認してください。

11. 試験公開環境（GitHub Pages）について
------------------------------------------------------------

このサイトは、県のWebサーバへ掲載する前の動作確認用として、
GitHub Pages という無料の静的サイト公開サービスで
試験公開する場合があります。

  ・GitHub Pages は「実際のHTTPSサーバ上で正しく動くか」を
    事前に確認するためだけのものです。
  ・本番の公開先は、あくまで県のWebサーバです。
  ・GitHub Pages 専用の作りにはしていません。
    ここにあるファイル一式をそのままコピーすれば、
    県のWebサーバでも同じように動作します。

フォルダ内の

  .nojekyll

は、GitHub Pages に対して「ファイルを加工せずそのまま配信する」ことを
指示するための空ファイルです。
県のWebサーバへ置いた場合、このファイルは何の影響も与えません。
削除しても構いませんが、そのままで問題ありません。
